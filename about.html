ABOUT CAT WEB

Welcome to CAT WEB, a small website made for people who love cats.

The project uses HTML to organize the pages, CSS to keep the classic web aesthetic, and JavaScript to request random cat images from TheCatAPI.

This site is also a small exercise in working with an external API and building a simple multi-page website.

Best viewed with Netscape Navigator at 800x600 resolution.
