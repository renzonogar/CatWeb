## CAT WEB: The Home Page of Cats

Um pequeno site inspirado nos websites da década de 1990, desenvolvido como atividade escolar para demonstrar o consumo de uma API utilizando HTML, CSS e JavaScript.
O site utiliza a **[The Cat API](https://api.thecatapi.com/v1/images/search)** para buscar imagens aleatórias de gatos e exibi-las na página.

O objetivo deste projeto é demonstrar, de forma simples, como uma página web pode se comunicar com uma API externa e utilizar os dados recebidos para atualizar seu conteúdo.
Para combinar com a proposta, o site foi desenvolvido com uma estética inspirada nos websites antigos da internet, principalmente páginas do final dos anos 90.
A ideia é simular um pequeno "portal de gatos" de 1998.
